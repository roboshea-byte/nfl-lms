# NFL LMS admin explainer

A 119-second, 1080p Remotion walkthrough for competition owners and administrators. It covers registration, the Admin home, entry payments, member support, pick overrides, results, announcements, deadlines and rollovers.

## Preview

```bash
npm install
npm run studio
```

## Render

```bash
npm run render
```

The MP4 is written to `output/nfl-lms-admin-guide.mp4`. The narration script is in `public/narration.txt`; `public/narration.wav` is the rendered British voice-over used by the composition.
